# Folio Desk 0.4.2

Click the grid icon beside a PDF or in a pane header to choose where that file appears. Pick a layout, select any combination of panes, and click **Apply**. For example, you can put the same worksheet in the top left and bottom right of a 2 × 2 grid.

Each PDF appears once in the sidebar. Its views keep their own page and zoom, and hidden views are available under **Show saved view** in the file’s context menu.
