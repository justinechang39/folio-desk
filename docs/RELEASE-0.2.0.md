# Folio Desk 0.2.0

## Continuous PDF scrolling

Scroll through all pages in each pane independently. Page-number controls, search results, and linked page navigation still work. Reading positions survive switching tabs, changing layouts, and restarting. Only pages near the viewport are rendered, with a per-pane raster memory budget.

## Saved appearance

The new Appearance picker offers Orange, Nord, Dracula, and Solarized palettes with System, Light, and Dark modes. Orange is the default, including for existing installations. Preferences are saved per user. PDF pages retain their original colors.

Existing workspaces are preserved. Download the Apple silicon ZIP and replace Folio Desk in Applications after quitting the old version. This app still requires macOS 13.3 or newer and is ad-hoc signed, not Apple-notarized.

Built and tested locally; GitHub Actions remains disabled.
