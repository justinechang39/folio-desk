# Folio Desk 0.4.0

Click the split-pane icon beside any document, or beside **Open…** in a PDF pane, to compare two views of the same file. You can also use **View → Compare Side by Side** or press **⌘\\**.

A new view starts at the current reading position. If a second view already exists, Folio reuses its saved position. Each side can scroll and zoom independently. The document list labels the two panes so you can jump to either one without opening another copy.

Download the Apple silicon ZIP, unzip it, and replace Folio Desk in Applications after quitting.
